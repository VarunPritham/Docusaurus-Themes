# Bricks Reference

Every brick, used once. This page is the canonical example of how a converted
Confluence page is written — copy the patterns here.

Plain markdown covers text, **bold**, headings, lists, tables, and code blocks.
Bricks cover everything Confluence does beyond markdown.

## Everything markdown already does

No bricks needed for any of this:

| Element | How |
|---|---|
| Headings, text, lists | plain markdown |
| Tables | markdown tables (this one) |
| Code blocks | fenced blocks with language tag |
| Table of contents | automatic — right-hand rail |
| Child page cards | `<DocCardList />` from `@theme/DocCardList` |
| Links between pages | relative markdown links |

```python
# Code blocks get syntax highlighting out of the box
def hello(name: str) -> str:
    return f"Hello, {name}"
```
