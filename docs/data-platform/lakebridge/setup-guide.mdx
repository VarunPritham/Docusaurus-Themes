## Install

```bash
pip install lakebridge --index-url https://artifactory.internal/api/pypi/simple
```

<Panel type="warning">
  Always install from the internal mirror. Direct PyPI access is blocked.
</Panel>

## Configure

```bash
lakebridge configure --transpiler-profile td-firm-v3
```

<Expand title="What the firm profile changes">
  The `td-firm-v3` profile maps the in-house Teradata UDFs and date macros
  that the generic profile does not recognise.
</Expand>
